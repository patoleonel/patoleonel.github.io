# Patricio Leonel Brite - Interactive Portfolio

This repository contains the source code for my interactive portfolio, showcasing my academic journey, professional experience, and personal projects.

## Architecture and Technologies

The portfolio is built as a static web application emphasizing performance, maintainability, and visual storytelling.

- **HTML5 & CSS3**: Semantic structure and custom styling with a focus on modern design principles (flexbox, CSS grid, smooth transitions, and border-radius aesthetics).
- **Vanilla JavaScript**: Handles state management, dynamic DOM manipulation, internationalization (i18n), and mathematical SVG drawing for the interactive timeline.
- **Responsive Design**: Fully adaptable layout ensuring a seamless experience across desktop, tablet, and mobile devices.
- **WebP Optimization**: All graphical assets are compressed and served in WebP format for optimal loading speeds and drastically reduced bandwidth consumption.

## Key Features

- **Interactive Timeline**: A dynamically rendered "spiderweb" timeline that visually connects academic milestones with professional experiences and key takeaways. The connections are drawn in real-time using SVG lines calculated via a ResizeObserver.
- **Bilingual Support**: Instantaneous switching between English and Spanish without page reloads.
- **Expandable Galleries**: Integrated inline accordion galleries for displaying certificates and project-specific imagery directly within the timeline nodes and side quests.
- **Project Showcase**: A dedicated section for GitHub repositories, directed short films, and other interactive media.

## Local Execution

To run this project locally, simply clone the repository and open the `index.html` file in any modern web browser. No build steps or package managers are required.

```bash
git clone https://github.com/patoleonel/patoleonel.github.io.git
cd patoleonel.github.io
```
